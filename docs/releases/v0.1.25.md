# Motor Setup Tool v0.1.25

- Open **Dynamixel** to configure XL330-M288-T and XL330-M077-T motors over a U2D2 adapter. The app can discover motors at 1 Mbps or the factory speed of 57,600 bps.
- Change the motor ID, baud rate, direction, or operating mode and save a reference pose as 0° (2048 pulses). The app backs up settings before writing and reads them back afterward.
- Reverse zero calibration has been observed immediately after saving on XL330 firmware 53 in Mode 5. Verify the reference position again after a power cycle. Other model, firmware, and mode combinations still need hardware verification.
