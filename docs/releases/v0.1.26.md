# Motor Setup Tool v0.1.26

- Use the desktop app in English or Korean. The app follows your system language by default. Switch languages in **Settings** without disconnecting a motor.
- When Dynamixel discovers several motors, select the ones you want to configure. **Save Zero** and **Backup** show the selected IDs even when a table filter hides a motor.
- Dynamixel connection errors clear when polling recovers. Starting the app from source now sets up its serial dependencies automatically.
