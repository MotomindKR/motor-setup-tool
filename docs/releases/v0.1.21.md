# Motor Setup Tool v0.1.21

- Linux DEB/RPM installers now set up GS-USB access automatically. Reconnect the USB adapter after installing, then refresh the adapter list.
- Fixed the title-bar divider ending at the Windows/Linux window buttons. The header stays 40 px tall.

The Windows installer is unsigned. macOS uses ad-hoc signing while Apple Developer verification is pending; install the DMG manually and use **System Settings → Privacy & Security → Open Anyway** if launch is blocked.
