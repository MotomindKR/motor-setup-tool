## Dynamixel setup

- Configure XL330-M288-T and XL330-M077-T motors over a U2D2 TTL adapter.
- Read live motor and joint angles, save the 2048-pulse zero, set direction,
  and change one motor ID with EEPROM readback verification.
- Set Current-based Position Control Mode (Mode 5) and verify the stored mode.
- Save 1,000,000 bps on one motor and verify the setting at the new speed.
- Discover factory-speed XL330 motors on connection and show each motor's
  stored baud rate in the motor table.
- Export settings and restore zero and direction using DXL Studio-compatible
  backups. Demo mode lets you try the same controls with virtual motors.
- Grant access to the selected Linux serial port through the system
  authorization prompt.

## Installers

- Windows x64 NSIS installer.
- Linux x64 and ARM64 DEB and RPM. Release CI checks DEB installation and
  startup on Ubuntu 20.04, 22.04, 24.04, and 26.04.
- macOS Apple silicon and Intel DMGs.

See the [Dynamixel guide](https://github.com/MotomindKR/motor-setup-tool/blob/v0.1.20/docs/dynamixel.md)
for connecting the adapter and checking EEPROM settings after a power cycle.
