# Motor Setup Tool v0.1.20

- Fixed the macOS backend startup crash caused by an invalid MuJoCo library signature.
- Replaced the Windows PowerShell updater with `electron-updater`. Windows uses NSIS, macOS uses Squirrel.Mac, and Linux uses DEB/RPM updates.
- Update installers preserve the Windows installation location and scope, and abort instead of stopping another motor process.
- Backend crashes now report the termination signal instead of “status null”.

Existing Windows installations need one manual installation to get the new updater.

The macOS build is ad-hoc signed while Apple Developer verification is pending.
Install the DMG manually; macOS in-app updates still require Developer ID signing.
If launch is blocked, attempt to open the app, then use **System Settings → Privacy & Security → Open Anyway**.
