# Motor Setup Tool v0.1.23

- The app checks for updates at launch and every four hours while open. A red dot on **Settings** shows when an update is available. Select **Install update** when you're ready.
- Refreshed the app icon with the centered Motomind M and a three-part motor dial.

The Windows installer is unsigned. On macOS, install the DMG manually while Developer ID signing is pending. If macOS blocks launch, use **System Settings → Privacy & Security → Open Anyway**.
