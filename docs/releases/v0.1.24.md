# Motor Setup Tool v0.1.24

- Calibration and jogging verify the selected actuator before enabling it. ID changes, zeroing, and firmware updates also check its identity.
- Jogging stops when the control loses focus. Changing calibration limits or disconnecting the adapter clears the previous review.
- New recordings store the motor’s CAN ID and eight-byte actuator UUID with the raw samples. Captured samples remain available if the stop check fails.
- If analysis was interrupted, open the saved run in **Files** and choose **Refit recording**. Refitting preserves the original samples.
- The saved runs list shows the latest report, and torque charts retain short peaks.
- On ad-hoc macOS builds, **Open download page** opens the matching release for manual installation.
