# Motor Setup Tool v0.1.18

- Rebuilt the frontend with Motomind UI components, simpler calibration controls, compact window chrome, and polished light/dark layouts.
- Added per-run ZIP and individual recording downloads, permanent run deletion, and visible actuator UUIDs.
- Corrected CAN register addresses and model-specific read/write permissions and persistence. See the [register audit](https://github.com/MotomindKR/motor-setup-tool/blob/v0.1.18/docs/registers.md).
- Refreshed official firmware downloads and kept the motor selected after firmware updates and CAN ID changes.
- Fixed false encoder discontinuities from buffered CAN replies and informational GS-USB recovery events being reported as faults.
- Jogging now uses the configured travel limit and brakes near the boundary while allowing reverse motion.
- Added RS-10P Classic CAN profiles, model detection, registers, and official firmware mapping. Physical RS-10P operation remains unverified; the jog and encoder fixes have regression/simulation coverage and still need hardware confirmation.
- Removed the old Rust GUI and unused dependencies; the macOS backend is now about 5 MB instead of 20 MB.

## Compatibility

- SLCAN support has been removed. Use a GS-USB adapter or Linux SocketCAN.
- Electron is the desktop interface. The Rust backend is CLI-only; use subcommands such as `can list`, `firmware check`, and `self-check` instead of the old hidden flags.
- Installers: Linux x64/ARM64 DEB and RPM, macOS ARM64 DMG, and Windows x64 EXE. Windows ARM64 is still unsupported. `SHA256SUMS` verifies the downloads.
